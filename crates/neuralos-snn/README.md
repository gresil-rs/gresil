# neuralos-snn

This crate moved to [`gresil`](https://crates.io/crates/gresil).

`neuralos-snn` 0.1.0-alpha.1 to 0.1.0-alpha.8 are the library's first
eight releases. From 0.1.0-alpha.9 it is published as `gresil`, from
the same repository, <https://gitea.com/gresil-rs/gresil>: write
`gresil = "0.1.0-alpha.9"` and `use gresil::` where you wrote
`use neuralos_snn::`. alpha.9's breaking changes are in its release
notes, <https://gitea.com/gresil-rs/gresil/releases/tag/v0.1.0-alpha.9>.
This last `neuralos-snn` has no code.
